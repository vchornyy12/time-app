# Android 1.0.3 — перший блок функціональної відповідності

23 жовтня 2026. versionCode: 4. Статус: перший блок етапу 1, не повна
відповідність вебверсії й не завершення всього етапу 1.

## Зміни

- Окрема вкладка Next Actions із пагінацією по 50 записів і фільтром
  контексту на стороні Supabase, до застосування limit.
- Відкриття деталей із Today, Inbox і Next Actions: редагування назви,
  вибір кількох контекстів, додавання контексту на поточну задачу.
- Inbox → Next Action одним update, який разом зберігає назву й контексти.
- Редактор перевіряє власника, початковий статус і updated_at. Застарілий
  редактор не перезаписує зміни іншого клієнта; є явне перечитування даних.
- Попередження перед втратою незбережених правок, блокування повторного
  запиту та закриття під час збереження, збереження вводу після помилки.
- Парольний вхід для наявних вебакаунтів. Magic link залишається альтернативою.
- Спільні Zod-схеми через портативний внутрішній імпорт; Metro бачить спільні
  runtime-модулі. React залишено точно 19.1.0, сумісним з native renderer.
- Для project next actions завершення використовує complete_project_step,
  зберігаючи атомарність із очищенням first_step_task_id. Повторне завершення
  вже виконаної задачі не оновлює її вдруге. Задачу, перенесену до іншого
  списку з другого клієнта, не можна випадково завершити зі старого рядка.

Нових міграцій і нових серверних endpoint немає. Дії цього блоку не
створюють/переносять Google-події. Майбутня календарна обробка потребує
спільного серверного інтерфейсу для побічних дій, як описано в аудиті.

## Перевірки

- 64 мобільні тести у 7 файлах: репозиторій, version/status guard, ліміти,
  пагінація, фільтр, auth, стани редактора, повторні натискання, помилки,
  незбережені зміни, збереження контекстів, сумісність React та існуючі тести.
- 89 тестів lib/validation/schemas.test.ts; mobile TypeScript; git diff --check.
- Gradle assembleRelease і статичні APK-перевірки пройшли.
- Точний артефакт встановлено поверх 1.0.2 на ARM64 Android 16 API 36.
- Через UI APK виконано парольний вхід тимчасовим тестовим акаунтом,
  відкриття Inbox-задачі, зміна назви, вибір @phone, Make Next Action,
  повторне редагування, Save changes, фільтр @home з порожнім результатом,
  фільтр @phone і завершення задачі. Стани next_actions і done перевірено
  окремим користувацьким клієнтом Supabase.
- Другий клієнт змінив іншу тестову задачу після відкриття редактора.
  Save changes у старому редакторі показав помилку, збережена назва другого
  клієнта залишилася незмінною. Reload latest task показав нову назву.
- Перевірено холодний повторний запуск зі збереженою сесією та crash log.
- Фізичний OnePlus і повний браузерний сценарій не перевірялися.
  Проєктний RPC перевірений модульно; нові екрани проєктів у цей APK не входять.

Тестові дані було ізольовано від існуючих користувачів в окремому тимчасовому
акаунті. Після перевірок акаунт і його дані видалено; емулятор вимкнено.
